# OpenPlayer DLSSNR Plugin 0.5.0

Experimental Windows x64 plugin for OpenPlayer 1.6.4 or later.

- Choose model preset 1 or Small preset 2 before enabling enhancement.
- Automatically recognize the RTX 30 optimized 0.4.0 runtime from
  [DLSS5-RTX-3080-laptop](https://github.com/lmxxf/DLSS5-RTX-3080-laptop)
  by SHA256 and use preset 2. Unknown runtimes retain preset 1 by default;
  a manual choice also supports other compatible runtimes.
- Existing GPU, live parameter, paused preview and frame-rate controls remain.

Supply the external `nvngx_dlssnr.dll` yourself. The plugin does not include
or download NVIDIA runtime binaries. The optimized upstream runtime targets
RTX 30 Ampere `sm_86`; other GPU generations are not covered by that claim.
The runtime is community modified and is not an official NVIDIA release.
The plugin uses CPU frame transport, so its end-to-end speed can differ from
Magpie or a model-only benchmark. SDR output and the existing 15 FPS default
remain; set a sustainable frame-rate limit for the selected GPU.
