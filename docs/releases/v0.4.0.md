# OpenPlayer DLSSNR Plugin 0.4.0

Experimental Windows x64 plugin for OpenPlayer 1.6.4 or later. Not a standalone
application or an official NVIDIA integration. Install the `.opplugin` through
OpenPlayer's plugin settings. Fully restart OpenPlayer when updating the plugin.

## Features

- Explicit, persisted GPU selection with automatic enumeration and failure retry.
- Live style, intensity, local tone/structure and skin-mask controls.
- Paused-frame preview without resuming playback.
- Selectable processing cadence: 10, 15 (default), 20, 24, 30 or source FPS.
- HDR/Dolby Vision input compatibility through conversion to SDR.
- Theme-aware controls and a side panel that avoids player chrome and transport.

## Limits

The NVIDIA runtime DLL and SDK are not included. Supply a trusted runtime that
you are authorized to use. Native modules run with user privileges, not in a
sandbox. Processing is experimental and uses CPU buffers plus GPU transfers.

A 15 FPS cap reduces motion smoothness; it does not provide 60 FPS inference.
No interpolation, super-resolution, HDR-preserving output or zero-copy path is
included. The user accepted this version; short GPU-1 tests verified paused
preview, synchronization and cleanup, not long-duration or real-time 4K guarantees.
