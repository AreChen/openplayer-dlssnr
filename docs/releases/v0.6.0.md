# OpenPlayer DLSSNR Plugin v0.6.0

Experimental plugin for OpenPlayer 1.6.10 or later on Windows x64 with a
compatible NVIDIA GPU.

- Recognize the RTX 30 optimized DLSSNR runtime and allow model preset selection.
- Adapt source-rate enhancement to measured GPU capacity, load, and playback speed.
- Add a configurable shortcut for the enhancement toggle and a dedicated icon.
- Compose with XeFG: enhancement runs before frame generation, regardless of the
  order in which the plugins are enabled.

The plugin does not include NVIDIA or third-party DLSSNR DLLs. Supply a trusted,
compatible runtime separately. Performance depends on the GPU and input; HDR
and Dolby Vision are converted to SDR, and real-time 4K is not guaranteed.
