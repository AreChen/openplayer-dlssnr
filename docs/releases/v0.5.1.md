# OpenPlayer DLSSNR Plugin 0.5.1

- Adapt source-rate enhancement to measured GPU capacity and current load.
- Preserve playback timing by repeating the latest enhanced frame when needed.
- Keep the existing fixed-rate settings and support older hosts with a 30 FPS
  compatibility cap when source rate is selected.

The earlier 0.5.0 changes add automatic recognition of the supported RTX 30
optimized runtime and model preset selection. The package does not include DLLs.
